# Loops

C has three loops: `while` checks its condition before each pass, `for` packs the start, the condition, and the step into one line, and `do`-`while` checks after each pass, so its body always runs at least once.
A loop ends only when its condition becomes false, so something in the body has to move it toward that.
`break` leaves the innermost loop right away, and `continue` skips the rest of the current pass and goes on with the next one.

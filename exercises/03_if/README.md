# If

C's `if` takes a condition in parentheses and treats any nonzero value as true and zero as false.
Without braces an `if` controls exactly one statement, whatever the indentation suggests.
`=` is assignment and `==` is comparison, and because an assignment is also an expression, mixing them up still compiles.
